# 新增レース再現的比賽

レース再現依 JRA 公布的成績重建每頭馬的位置。資料直接照成績表手動抄寫即可，不需要寫爬蟲。

## 步驟

1. 在 `src/course/races/` 建立新檔，例如 `derby2024.js`，照下方範本填寫。
2. 在 `src/course/races/index.js` 匯入它，加進 `ALL_RACES`：
   ```js
   import { DERBY_2024 } from './derby2024'
   export const ALL_RACES = [JAPAN_CUP_2023, DERBY_2024]
   ```
3. 執行檢查：
   ```bash
   pnpm --filter racecourse-3d test
   ```
   資料有誤時，`validate.test.js` 會列出哪一列、哪一個欄位有問題（見下方「檢查訊息」）。
4. 執行 `pnpm dev:race`，在面板「模擬跑法 → 再現」點新比賽，或直接開 `?replay=<id>`。

資料有誤的比賽不會出現在面板上，瀏覽器 console 會印出原因，頁面不會因此壞掉。

## 範本

```js
// 第91回東京優駿(GI)（2024 年 5 月 26 日 東京 11R、芝左 2400m、良）
// 出處：JRA 成績（填你抄寫的來源網址）

export const DERBY_2024 = {
  id: 'derby2024', // 網址 ?replay= 用的代號：英數字，不可與其他比賽重複
  label: '2024 ダービー', // 面板按鈕上的短名稱
  name: '第91回東京優駿(GI)', // 名次表上方顯示的正式名稱
  date: '2024-05-26',
  runId: 'turf-2400', // 芝：turf-距離；ダート：dirt-距離
  going: '良',
  source: 'https://…',
  laps: [12.5, 11.0 /* …先頭馬每 200m 的ハロンタイム，依序全部抄 */],
  corners: [
    '…1コーナー的通過順位，整行照抄…',
    '…2コーナー…',
    '…3コーナー…',
    '…4コーナー…',
  ],
  horses: [
    // 依「着順」由 1 着往下排，每頭一列
    { number: 1, name: '馬名', time: '2:24.3', margin: '', last3F: 34.0 }, // 1 着的着差留空
    { number: 7, name: '馬名', time: '2:24.4', margin: '1/2', last3F: 33.8 },
    // …
  ],
}
```

## 欄位對照成績表

| 欄位 | 成績表上的名稱 | 寫法 | 範例 |
|---|---|---|---|
| `number` | 馬番 | 數字 | `2` |
| `name` | 馬名 | 字串 | `'イクイノックス'` |
| `time` | タイム（走破タイム） | `分:秒.十分位` | `'2:21.8'`，1 分內寫 `'59.4'` |
| `margin` | 着差 | 字串，照抄；1 着留空 `''` | `'4'`、`'3/4'`、`'1.1/2'`、`'クビ'` |
| `last3F` | 上り／上がり3F | 秒數（數字） | `33.5` |
| `laps` | ハロンタイム／ラップ | 數字陣列，依序抄完 | `[12.7, 11.3, …]` |
| `corners` | コーナー通過順位 | 每個コーナー一行字串，照抄 | `'8=3,2(1,17)(5,14)…'` |

- `horses` 必須依着順排列：程式以排列順序決定到達先後（同タイム時用着差區分）。
- `laps` 的段數 = 距離 ÷ 200 無條件進位（2400m 為 12 段；2500m 為 13 段，第一段是 100m）。合計要等於 1 着的タイム（容許 ±0.3 秒）。
- `corners` 抄成績表上「コーナー通過順位」那幾行，每行要包含全部出走馬各一次。1600m 這類只過兩個コーナー的比賽就只有兩行（3コーナー、4コーナー）。

## 資料在哪裡找

以下任一來源都有完整欄位，挑一個抄即可：

- **JRA 公式網站**：「競馬・データ → レース結果」，或每場的「成績」頁。
- **netkeiba データベース**：`https://db.netkeiba.com/race/<レースID>/`。レースID 為 12 碼：年 4 碼＋場 2 碼（東京 `05`）＋回 2 碼＋日 2 碼＋R 2 碼。例：2023 年 5 回東京 8 日 12R → `202305050812`。
- **JBIS**：日本軽種馬協会的資料庫。

大量匯入時建議用 JRA 官方的 JRA-VAN Data Lab，不要大量抓取上述網站（請遵守各網站使用條款）。

## コーナー通過順位的記號

依 JRA 的定義：

| 記號 | 意思 | 程式換算 |
|---|---|---|
| `( )` | 1 馬身未滿、並走的馬群；**括號內由內側往外側排** | 同一位置，依序往外一個身位 |
| 兩組之間沒有記號 | 1 馬身未滿 | 0.7 馬身 |
| `,` | 1 馬身以上 2 馬身未滿 | 1.5 馬身 |
| `-` | 2 馬身以上 5 馬身未滿 | 3.5 馬身 |
| `=` | 5 馬身以上（沒有上限） | 只保證至少 5 馬身，實際差距由各馬時間決定 |

有些網站會在括號內的先頭馬加 `*` 或其他標記，程式會忽略數字和上表記號以外的字元，照抄即可。

## 着差的寫法

可用：`ハナ`、`アタマ`、`クビ`、`1/2`、`3/4`、`1`、`1.1/4`、`1.1/2`、`1.3/4`、`2`、`2.1/2`、`大`、`同着`，以及其他整數。`1.1/2` 表示「1 又 1/2 馬身」。

## 檢查訊息

| 訊息開頭 | 該檢查的地方 |
|---|---|
| `runId … 不是可用的距離` | 距離是否在 `src/course/courseData.js` 的 `RACE_DISTANCES`；芝、ダート寫錯 |
| `馬番須為 1〜N 各一次` | 有馬番重複或漏抄 |
| `第 k 列 … タイム` | 時間格式，應為 `2:21.8`（冒號、小數點） |
| `第 k 列 … 着差` | 着差拼字（見上方可用寫法）；1 着要留空 |
| `horses 須依着順排列` | 列的順序；或某列タイム抄錯 |
| `ハロンタイム有 n 段` / `合計 … 不符` | 少抄或多抄一段，或某段數字打錯 |
| `コーナー k 缺少／重複出現` | 該行通過順位漏抄或重複某個馬番 |

## 重現的方式與限制

- **確定的點**：每頭馬在 0 秒位於閘門、在「タイム − 上がり3F」時位於剩 600m、在タイム時位於終點。
- **道中**：沿用先頭馬ハロンタイム的配速形狀，縮放到剛好在各自的時刻通過剩 600m；コーナー通過順位微調前後差與內外位置。
- **內外位置是推估**：只有コーナー通過順位的括號提供內外資訊，直線上沿用最後一個コーナー的位置，重播時沒有碰撞處理。
- **仮柵（A〜D コース）**：沿用面板上選的コース，資料檔不記錄。
- 只支援 `RACE_DISTANCES` 列出的距離（東京競馬場實際使用的距離）。
